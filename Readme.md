# My Awesome Blog Website

A simple, responsive blog website built purely with HTML, CSS, and vanilla JavaScript.

## Features

*   **Multi-page Layout:** Includes Home, Blog, About, and Contact pages.
*   **Responsive Design:** Adapts gracefully to desktop, tablet, and mobile screen sizes using CSS media queries and flexible layouts.
*   **JavaScript Interactivity:**
    *   **Mobile Menu Toggle:** A functional hamburger menu for smaller screens.
    *   **Contact Form Validation:** Basic client-side validation for the contact form fields (name, email, message).
*   **Clean Code:** Semantic HTML and well-organized CSS.
*   **Deployment Ready:** Easily deployable to static hosting services like GitHub Pages.

## How to Use

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/blog-website.git
    cd blog-website
    ```
    *(Replace `your-username` with your actual GitHub username)*

2.  **Open in Browser:**
    Simply open the `index.html` file in your web browser to view the site locally.

3.  **Customize:**
    *   Edit the content within the `.html` files (text, images, links).
    *   Modify the appearance by changing styles in `style.css`.
    *   Adjust or add JavaScript functionality in `script.js`.

## Deployment via GitHub Pages

1.  **Push to GitHub:** Make sure your project code is pushed to a GitHub repository.
2.  **Go to Settings:** In your GitHub repository, navigate to the "Settings" tab.
3.  **Select Pages:** In the left sidebar, click on "Pages".
4.  **Configure Source:**
    *   Under "Build and deployment", select "Deploy from a branch" as the source.
    *   Choose the branch you want to deploy from (usually `main` or `master`).
    *   Select the folder `/ (root)`.
    *   Click "Save".
5.  **Visit Site:** GitHub Pages will build your site and provide a URL (like `https://your-username.github.io/blog-website/`). It might take a minute or two. Visit the provided link to see your live blog! Remember to update the link in this README.
